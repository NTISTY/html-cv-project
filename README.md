# Responsive Personal Portfolio

A modern, fully responsive personal portfolio website built with HTML, CSS, and JavaScript. Optimized for mobile devices with a clean, professional design.

## Features

✨ **Responsive Design**
- Mobile-first approach
- Fully responsive on all devices (mobile, tablet, desktop)
- Optimized for screens as small as 320px

🎨 **Modern UI/UX**
- Gradient backgrounds and smooth animations
- Smooth scrolling navigation
- Interactive hover effects
- Professional color scheme

📱 **Mobile Optimized**
- Hamburger menu for mobile devices
- Touch-friendly interface
- Optimized font sizes for readability
- Fast loading times

🚀 **Performance**
- Minimal dependencies (only Font Awesome icons)
- Optimized CSS and JavaScript
- Lazy loading support
- Smooth animations and transitions

## Sections

1. **Navigation Bar** - Sticky navigation with mobile menu toggle
2. **Hero Section** - Eye-catching introduction with CTA buttons
3. **About** - Personal introduction and statistics
4. **Skills** - Display of technical skills with icons
5. **Projects** - Featured project showcase
6. **Contact** - Contact form and information
7. **Footer** - Footer with links

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, Media Queries
- **JavaScript (ES6+)** - Interactivity and animations
- **Font Awesome** - Icon library

## Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/NTISTY/html-cv-project.git
cd html-cv-project
```

2. Open `index.html` in your browser:
```bash
open index.html
```

Or use a local server:
```bash
python3 -m http.server 8000
```

## Customization

### Update Personal Information

Edit `index.html` to add your:
- Name and title
- Profile image (replace placeholder)
- About section content
- Skills
- Projects
- Contact information

### Change Colors

Modify CSS variables in `styles.css`:

```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    /* ... other colors ... */
}
```

### Add Your Content

1. **Profile Image**: Replace the placeholder image URL
2. **About Section**: Update the bio and statistics
3. **Skills**: Add your technical skills
4. **Projects**: Add links and descriptions of your projects
5. **Contact**: Update contact information

- **Mobile Menu Toggle**: Opens/closes menu on mobile devices

## Deployment

### Deploy to GitHub Pages

1. Push code to GitHub
2. Go to repository Settings
3. Enable GitHub Pages from main branch
4. Your portfolio is live at: `https://username.github.io/html-cv-project`

### Deploy to Other Platforms

- **Netlify**: Drag and drop folder or connect GitHub
- **Vercel**: Similar to Netlify, simple deployment
- **Your own server**: FTP the files to your server
